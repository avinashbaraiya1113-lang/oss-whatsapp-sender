OSS WhatsApp Sender

Excel/CSV સંપર્ક યાદીમાંથી વ્યક્તિગત WhatsApp મેસેજ તૈયાર કરો

1. Excel / CSV ફાઇલ ઉમેરો

ફાઇલમાં Name અને Phone કૉલમ રાખો. ફોન નંબર country code સાથે હોય તો સારું (ભારત માટે 91).

હજુ કોઈ ફાઇલ પસંદ કરી નથી.

2. WhatsApp કનેક્શન / ગ્રુપ માહિતી

તમારા પોતાના WhatsApp અથવા WhatsApp Webમાં લૉગિન કરવા માટે અધિકૃત WhatsApp ખોલો. આ વેબસાઇટ તમારા WhatsAppના ગ્રુપ અથવા સભ્યોની યાદી વાંચતી નથી.

કનેક્શન સ્થિતિ: તપાસવાની બાકી
મહત્વપૂર્ણ: WhatsAppની સામાન્ય અધિકૃત સુવિધા અન્ય લોકોના ગ્રુપના સભ્યોના ફોન નંબર આ ટૂલને આપતી નથી. તેથી ગ્રુપમાંથી છુપાઈને સભ્યોના નંબર મેળવવા અથવા આપમેળે મેસેજ મોકલવાની સુવિધા ઉપલબ્ધ નથી. તમે સંમતિ આપેલા સંપર્કોની યાદી Excel/CSVથી ઉમેરો.

3. તમારો મેસેજ લખો

નામ માટે {name} લખો. ઉદાહરણ: નમસ્તે {name}, અમારી નવી ઓફર જુઓ.

4. સંપર્ક યાદી અને પ્રગતિ

0કુલ સંપર્કો
0માન્ય નંબર
0તમે મોકલ્યા તરીકે ચિહ્નિત કર્યા
આ ટૂલ દરેક સંપર્ક માટે WhatsAppની અલગ ચેટ ખોલે છે. મેસેજ મોકલવાનું અંતિમ બટન WhatsAppમાં તમારે જ દબાવવાનું છે. માત્ર તમારી પાસે કાયદેસર રીતે પ્રાપ્ત થયેલા અને મેસેજ મેળવવાની સંમતિ આપેલા સંપર્કોનો ઉપયોગ કરો. અજાણ્યા ગ્રુપ સભ્યોના નંબર કાઢવા અથવા અનિચ્છિત બલ્ક મેસેજ મોકલવા માટે આ ટૂલ નથી.
નામફોનસ્થિતિક્રિયા
Excel/CSV અપલોડ કરો.

5. વ્યક્તિગત મેસેજ તૈયાર કરો

એક સમયે એક સંપર્કની WhatsApp ચેટ ખોલો. મેસેજ ચેટમાં ભરેલો આવશે; મોકલતા પહેલાં તપાસો અને Send દબાવો.

સંપર્ક લોડ થયા પછી અહીં દેખાશે.
