ઝડપી શરૂઆત

દરેક Excel/CSV અપલોડ અલગ લિસ્ટ બને છે. કેમ્પેઇન શરૂ કરતી વખતે એક ચોક્કસ લિસ્ટ પસંદ કરશો તો ફક્ત એ જ લિસ્ટના સંપર્કો આવશે.

મહત્ત્વપૂર્ણ: આ ટૂલ WhatsApp ગ્રુપમાંથી સભ્યોના ખાનગી નંબર કાઢતું નથી. WhatsApp Web અથવા સત્તાવાર API પણ આપમેળે બધા ગ્રુપ સભ્યોની યાદી આપતી નથી. ફક્ત કાયદેસર રીતે મળેલા અને મેસેજ માટે સંમત થયેલા સંપર્કો ઉમેરો.
